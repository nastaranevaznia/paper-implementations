# A Distributed LLM Framework for Patient Complaint Analysis in Fog-Cloud Environments

## 📝 Overview

Python implementation of the paper:

> **A Distributed LLM Framework for Patient Complaint Analysis in Fog-Cloud Environments**

With a single command, the code reproduces the comparison table and all three figures from the paper.

## 👥 Authors

- Nastaran Evaznia
- Azadeh Kazemi

## 🚀 Quick Start

```bash
cd fclf
pip install -r requirements.txt
python main.py
```

## 📦 Requirements
numpy, pandas, matplotlib, seaborn, scikit-learn, scipy
